ImageFree 自动配图
AI 每回复一楼，自动挑一段剧情出图，并把图片插在这段文字的后面 （不是塞到楼层底部的图廊里）。
填到 /v1 为止。本地中转就是 http://127.0.0.1:8080/v1。 中转服务默认要求 1234567A；留空会被回 401。
独立 API 重写：另配一条 OpenAI 兼容接口，只干「正文 → 绘图提示词」， 不读对话预设、不占对话额度、不往聊天里塞标签 —— 换任何预设都不受影响。
直接取正文：挑本楼最像画面的一段直接当提示词，长文容易出乱图。
旧方案：走酒馆的 quiet prompt，等于用当前预设再写一遍 —— 这正是 「重写逻辑被绑进预设」的老毛病，仅为兼容保留。
提示词重写 API
选复用主 API 就不用再填 Key：请求走酒馆自己的 /api/backends/chat-completions/generate， Key 始终留在服务端。同样不读预设、不写聊天记录， 只是借一条通道把「正文 → 提示词」跑掉。
想固定用别的模型？先在酒馆「连接管理器」里存一个档案，这里就能选。 选档案时会忽略档案自带的预设（不会把出图规则带跑）。
任何 OpenAI 兼容的 /chat/completions 都行（DeepSeek、Qwen、GLM、本地 Ollama / LM Studio…）。 地址填到 /v1 为止；只填域名会自动补 /chat/completions。
风格后缀会拼在模型写出的提示词后面，模型本身不用写画质词 —— 想统一画风改这里就行。 清空这个框 = 回到内置规则（内置规则已按「一段正文 → 一条提示词」调好）。 可用占位符：{{char}} {{user}} {{story}} {{index}} {{count}} {{style}}
